📺 WEB_DEV_NETFLIX_CLONE

A fully responsive Netflix landing page clone created using **HTML**, **CSS**, and **JavaScript**. This project is part of my front-end web development learning journey, designed to practice layout building, responsive design, and UI structuring based on a real-world platform's interface.

The project replicates the look and feel of Netflix's India landing page, including interactive FAQs, multiple feature sections, and a clean CTA-driven hero section. It focuses on using semantic HTML5, organized CSS styling, and basic JavaScript functionalities to deliver a smooth, user-friendly experience.

 📌 Features

- ✅ Fully responsive Netflix landing page clone
- ✅ Hero section with background image, titles, descriptions, and CTA
- ✅ Feature highlight sections with images, videos, and device mockups
- ✅ Accordion-style FAQ section for interactive content toggling
- ✅ Custom footer with multiple navigation columns
- ✅ Organized, semantic HTML5 structure
- ✅ Clean CSS for layout, typography, and responsiveness
- ✅ Scalable base for adding more interactivity via JavaScript

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome (for icons)
